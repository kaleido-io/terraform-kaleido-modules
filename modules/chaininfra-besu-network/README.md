# chaininfra-besu-network

Deploys a Besu network (`kaleido_platform_network`, type `Besu`) and the
`chain_infrastructure` stack that wraps it. By default the network initializes in
`automated` mode, bootstrapping a genesis from `bootstrapOptions` (QBFT consensus,
EIP fork config, block-config flags, and optional initial validators/balances).

Supply `genesis_json` to switch to `manual` init mode with a caller-owned genesis.

## Required settings

| Setting | Description |
|---------|-------------|
| `environment_id` | Kaleido environment to deploy the network and stack into |

## Optional settings

| Setting | Default | Usage |
|---------|---------|-------|
| `network_name` | `besu` | Display name of the `BesuNetwork` |
| `stack_name` | `besu` | Display name of the chain-infrastructure stack |
| `init_mode` | `automated` | `automated` bootstraps from `bootstrapOptions`; `manual` expects an external genesis; forced to `manual` when `genesis_json` is set |
| `genesis_json` | `null` | Inline genesis JSON; network uses this verbatim in `manual` init mode |
| `chain_id` | `null` | Network chain ID; generated by the platform in `automated` mode when unset |
| `qbft` | `{ blockperiodseconds = 5 }` | QBFT consensus configuration |
| `eip_block_config` | Shanghai and Osaka at genesis | EIP fork activation timestamps |
| `block_config_flags` | `{ zeroBaseFee = true }` | Boolean flags injected into the genesis config |
| `initial_validators` | `[]` | Validator addresses to seed into the genesis block |
| `initial_balances` | `{}` | Address-to-balance map to pre-fund in the genesis block |
| `target_gas_limit` | `null` | Maximum gas per block; `null` uses the platform default |

## Usage

### Automated Initialized Network
Initializes the network automatically based on the `qbft` setting and generates a genesis for the network on creation.
 
```hcl
module "besu_network" {
  source = "git@github.com:kaleido-io/terraform-kaleido-modules.git//modules/chaininfra-besu-network?ref=main"

  environment_id = kaleido_platform_environment.env.id
  network_name   = "besu"
  stack_name     = "besu"

  initial_balances = {
    "0x12F62772C4652280d06E64CfBC9033d409559aD4" = "0x111111111111"
  }
}
```

### Bring-your-own genesis

Render the genesis in HCL and supply it inline. The network switches to `manual`
init mode and consumes the file verbatim as the `init` file set, so you own and
upgrade the genesis over time:

```hcl
module "besu_network" {
  source = "../../modules/chaininfra-besu-network"

  environment_id = kaleido_platform_environment.env.id
  genesis_json = jsonencode({
    config = { chainId = 12345, shanghaiTime = 0, qbft = { blockperiodseconds = 5 } }
    # ...
  })
}
```

## Outputs

| Output | Description |
|--------|-------------|
| `network_id` | ID of the `BesuNetwork` |
| `stack_id` | ID of the chain-infrastructure stack wrapping the network |
| `network_name` | Display name of the `BesuNetwork` |
| `chain_id` | Chain ID captured after creation (generated in `automated` mode when unset) |
| `network_info` | Full top-level network config captured after creation |
