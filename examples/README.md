## Examples

All examples are for demonstration purposes and reference only. They are not modules with a guarantee of backwards compatibility, and are liable to have breaking changes in any release.
They provide tested usages of the Kaleido Terraform modules with the latest Kaleido Enterprise Platform release, and the latest release of the Terraform provider.

- [`chaininfra-paladin`](./chaininfra-paladin) - Example of using the Kaleido Terraform modules to deploy a Paladin network with N nodes, including its prerequisites: a Besu base ledger with an EVM gateway, and a Key Manager with an HD wallet.
- [`digitalassets-custody`](./digitalassets-custody) - Example of using the Kaleido Terraform modules to deploy a Custody stack with a single environment with EVM and BTC connectors.
- [`v1.2.x`](./v1.2.x) - Older examples from the Terraform provider v1.2.x release.
